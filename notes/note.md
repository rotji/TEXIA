# TEST 002 — MULTI-SOURCE CONFLICT INVESTIGATION

Now we can start the actual next experiment.

## Objective

Test whether TEXIA can handle a situation where:

* multiple sources discuss the same subject;
* sources make different claims;
* some claims are stronger than others;
* information appears contradictory;
* timelines overlap;
* actors have different perspectives;
* evidence is incomplete;
* some apparent contradictions are actually state transitions.

This directly stress-tests what we learned in Phase 04.

---

# Test 002 Question

We need a case with a structure approximately like:

```text
SOURCE A
   │
   ├── Claim X
   │
SOURCE B
   │
   ├── Claim Y
   │
SOURCE C
   │
   ├── Claim Z
   │
   ↓
TEXIA
   │
   ├── Same entity?
   ├── Same event?
   ├── Same claim?
   ├── Same time?
   ├── Same state?
   ├── Same scope?
   ├── Same epistemic status?
   │
   ↓
CONFLICT ANALYSIS
   │
   ├── genuine contradiction
   ├── temporal difference
   ├── scope difference
   ├── semantic difference
   ├── epistemic difference
   ├── entity ambiguity
   └── unresolved
```

---

# Test 002 should NOT simply ask:

> "Which source is telling the truth?"

That's too simplistic.

Instead:

> **"What can TEXIA reconstruct when credible sources provide apparently incompatible descriptions of the same evolving situation?"**

That is a much stronger test.

# 002.6 Search for the missing transition

This is one of the most important things we now want to test.

Suppose:

```text

```

we ask:

```text
X
│
│

│

│
└── no transition possible?
│
↓
Y
```

If the transition isn't found:

> **OPEN TRANSITION**

That becomes an investigation target.

# 002.7 Produce the intelligence output

```text

What evidence supports each conclusion?

What should we investigate next?
```
