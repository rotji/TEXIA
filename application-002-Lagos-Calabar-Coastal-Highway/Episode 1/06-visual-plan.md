# Visual Plan

## 1. Purpose

This document defines the visual evidence required for Episode 1 of the Lagos–Calabar Coastal Highway investigation.

The purpose is to determine:

* what the audience needs to see;
* why they need to see it;
* what claim or question the visual supports;
* what source the visual comes from;
* what the visual actually establishes;
* what it does not establish;
* how it should be presented.

The visual plan is not a collection of attractive images.

The governing principle is:

```text
CLAIM / QUESTION
      ↓
WHAT DOES THE VIEWER NEED TO SEE?
      ↓
VISUAL EVIDENCE
      ↓
SOURCE
      ↓
DATE / LOCATION
      ↓
WHAT IT ESTABLISHES
      ↓
LIMITATION
```

---

# 2. Visual Evidence Rules

## Rule 1 — Every important visual must have a purpose

Before using a visual, ask:

> Why does the viewer need to see this?

If the answer is only:

> "It looks good."

the visual should normally not be used.

---

## Rule 2 — Do not imply more than the visual proves

A photograph of construction equipment proves that the equipment was present.

It does not automatically prove:

* project completion;
* project cost;
* percentage completion;
* contractor performance;
* legality;
* quality of construction.

---

## Rule 3 — Date visuals whenever possible

Every important visual should record:

```text
DATE
SOURCE
LOCATION
ORIGINAL CONTEXT
```

If the date is unknown, label it accordingly.

---

## Rule 4 — Preserve original context

Do not crop, edit, annotate, or manipulate an image in a way that changes its meaning.

Where annotations are necessary:

* preserve the original;
* create a separate annotated version;
* clearly indicate that the annotation is ours.

---

## Rule 5 — Do not use illustrative imagery as evidence

Generic images of:

* highways;
* construction workers;
* bulldozers;
* Lagos;
* beaches;
* bridges;

may be useful for visual transitions.

They must not be presented as evidence of the Lagos–Calabar project unless they actually depict the project.

## VISUAL 018 — What Is Chainage?

### Purpose

### Visual

```text

  |
  |---- 15+000
  |

  |
```

### Explanation

Chainage is a distance reference used along an engineering alignment.

### Why it matters

It allows different documents to refer to specific points along the project.

# 22. Visual Manipulation Rules

Allowed:

* cropping for presentation;
* highlighting relevant text;
* adding arrows;
* adding labels;
* adjusting readability;
* creating maps from verified geographic data.

Required:

* retain original source;
* preserve meaning;
* clearly distinguish original material from our annotations.

Not allowed:

* altering evidence;
* moving geographic features;
* changing dates;
* removing context that changes meaning;
* presenting illustrative graphics as original evidence.

---

# 23. Map Rules

Maps are especially sensitive because viewers naturally interpret them as precise.

Therefore every map must identify whether it is:

### Exact

Based on verified geographic coordinates or engineering geometry.

### Approximate

Based on publicly available information where exact geometry is unavailable.

### Illustrative

Created only to explain a concept.

### Historical

Represents a particular dated state.

### Current

Represents the latest verified state.

A map must never silently move from one category to another.

# 26. Visual Decision Rule

Before adding a visual, ask:

```text
DOES IT HELP THE VIEWER
UNDERSTAND THE EVENT?
        OR
VERIFY THE CLAIM?
        OR
UNDERSTAND THE GEOGRAPHY?
        OR
UNDERSTAND THE CHANGE?
        OR
UNDERSTAND THE UNCERTAINTY?
```

If none apply:

> Do not add it.

---

# 27. Final Visual Principle

The documentary should not merely **tell the viewer what happened**.

It should give the viewer opportunities to **see why we believe what we are saying**.

Therefore:

```text
NARRATION
    +
DOCUMENT
    +
MAP
    +
PHYSICAL EVIDENCE
    +
DATE
    +
SOURCE
    ↓
UNDERSTANDABLE INVESTIGATION
```

Every important visual should increase either:

**understanding, verification, or transparency.**

If it does none of those things, it is probably decoration rather than evidence.
