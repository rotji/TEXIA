# Episode 1

## Lagos–Calabar Coastal Highway Documentary Investigation

**Status:** Working template

**Episode:** 1

## Purpose

This folder contains the planning and working documents for Episode 1 of the ongoing public documentary investigation.

Episode 1 should establish, using verified evidence:

* the project
* its history
* major changes
* financing and construction context
* current state
* the questions that justify continuing the investigation

## Evidence rule

Use only evidence already established in the investigation or evidence subsequently verified.

Do not convert claims, allegations, interpretations, or unresolved questions into conclusions.

## Scope boundary

Episode 1 is an introductory investigation.

Detailed alignment analysis, Okun-Ajah/Winhomes, demolition, compensation, and detailed money-trail investigations are reserved for later episodes unless verified evidence shows that limited context is necessary to explain Episode 1.

## Episode 1 workflow

Use the documents in this order:

```text
01-timeline.md
	↓
02-source-plan.md
	↓
03-evidence-plan.md
	↓
04-claims.md
	↓
05-unknowns.md
	↓
06-visual-plan.md
	↓
07-story-structure.md review
	↓
08-script.md
	↓
09-production.md
	↓
10-publication.md
```

The workflow separates investigation from public storytelling. The timeline, source plan, evidence plan, claims, and unknowns establish the evidence boundary. The visual plan and story structure then translate that established record into a public episode. The script, production plan, and publication record must not introduce unsupported facts.

`00-episode-definition.md` defines the episode's scope and boundaries before this workflow begins. `README.md` governs navigation; it does not replace the individual investigation records.
